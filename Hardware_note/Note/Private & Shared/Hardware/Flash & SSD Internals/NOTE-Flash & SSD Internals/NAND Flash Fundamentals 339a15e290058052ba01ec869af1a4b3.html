Key Word Definition/ Discussion
SLC、MLC、TLC、QLC

NAND flash 的基本儲存單元是 floating-gate transistor（或是較新的 charge-trap cell-3D NAND flash）。透過在 floating gate (或insulating nitride layer)中注入不同數量的電子，改變電晶體的 threshold voltage。讀取時根據電壓區間判斷對應的 bit 值。在 MLC/TLC/QLC 中，一個 cell 會對應多個電壓區間，從而儲存多個 bits。

NAND Flash Type

SLC（Single-Level Cell）：1 bit/cell，區分 2 個電壓等級
MLC（Multi-Level Cell）：2 bits/cell，區分 4 個電壓等級
TLC（Triple-Level Cell）：3 bits/cell，區分 8 個電壓等級
QLC（Quad-Level Cell）：4 bits/cell，區分 16 個電壓等級

Pitfall: QLC is a "bad SLC".

Correct Concept: Engineering Trade-off (QLC’s voltage margin between levels is very narrow.)

QLC vs. SLC

  1. 儲存資料難度上升：主控在寫入(programming)資料時，需要精確控制浮柵中電子的數量；

    TLC 的 program time 約 1-2 ms，QLC 更慢

  1. 讀取資料的難度上升：主控在讀取資料時，也必須非常精確地判斷目前電壓屬於哪個區間(需要更多次的 voltage sensing )，否則可能導致誤讀；

    SLC 讀取約 25 us，TLC 約 50-75 us，QLC 可達 100+ us

  1. 耐久性(endurance)降低：儲存資訊越多，對電壓精度要求越高。Voltage Margin 越窄，能容忍的損傷就越少。而每次 program/erase 都會對氧化層造成損傷，次數越多、浮柵的磨損越大、電壓狀態越不穩定。
  1. 容量增加：同樣數量的 cell，QLC 的容量是 SLC 的 4 倍。

Cell, Page(R/W), Block(ERASE), Plane, Die

NAND FLASH Storage Hierarchy:

一個Device有若干個DIE （或叫LUN ），每個DIE有若干個Plane ，每個Plane有若干個Block ，每個Block有若干個Page 。每個(或多個)Page對應一個Wordline ，由成千上萬個儲存單元(cell)構成。

由小到大結構:

Cell → Page → Block → Plane → Die → Device

Detail of each architecture

  • Page（典型大小 4-16 KB）：最小的讀取與寫入單位。你不能只寫 512 bytes，必須寫滿一整個 page。
  • Block（典型大小 256-512 個 page，即 4-8 MB）：最小的抹除單位 (erase)。這個粒度差異是 SSD 設計複雜度的根源。
  • Plane：一個 die 內通常有 2-4 個 plane。同一個 die 的不同 plane 可以並行操作（multi-plane operation），這是 SSD 提升吞吐量的重要機制。
  • Die：一個獨立的 NAND flash 晶片。一顆 SSD 裡可能有 4-16 個 die，controller 可以對不同 die 發出獨立的指令（die-level parallelism）。

Important:

讀寫粒度是 page（16 KB），但抹除粒度是 block（4 MB 以上），這個 250 倍以上的粒度差異，是為什麼有 SSD 管理機制的根本原因。

Block Architecture

WordLine對應著一個或若干個Page ，取決於SLC,MLC或TLC 。對SLC來說，一個WordLine對應一個Page ； MLC則對應2個Page ，這兩個Page是一對： Lower Page和Upper Page ； TLC對應3個Page 。

Page有多大，WordLine上面就有多少個儲存單元（ Cell ），就有多少個Bitline 。

Block 當中的所有這些儲存單元（ Cell ）都是共用一個基板的

Erase-before-write

固態的擦除是以block為單位、讀寫以page為單位，Nand的物理特性決定了他不能覆蓋寫入。

Nand flash 使用浮動柵級晶極管儲存電子，每個cell僅能由0→1 (注入電子)。而ERASE這個動作是指對一整個Block施加高壓電，將所有電子移除(回復到0的狀態)，以重新寫入數據。

因此如果我們要對一個已有資料的page進行寫入或是修改時，必須先把這個page所在的block中的資料讀出、將block清空後再把所有資料寫入(而這樣會耗費很大的時間，因此SSD又延伸出Flash Translation Layer以降低讀寫latency)。

Flash Translation Layer(out-of-place write controller)

如果每次更新一個 16 KB 的 page 都要搬移整個 4 MB block 的資料，效率豈不是極差？沒錯，所以 SSD 根本不這麼做。SSD 採用 out-of-place write 策略：更新 page 1 時，直接把新資料寫到另一個空白的 page，再更新 mapping table 讓邏輯位址指向新位置。舊的 page 變成 invalid，等之後 garbage collection 來清理。

P/E cycle limitations and SSD lifespan

每次 erase 操作都會對 cell 的隧穿氧化層（tunnel oxide）造成微小但不可逆的損傷。隨著 P/E cycle 累積，氧化層的絕緣能力下降，cell 的 threshold voltage distribution 會逐漸擴散、重疊，最終無法正確區分不同的電壓等級。

P/E cycle 限制不只影響壽命，也影響 data retention。一顆新的 TLC SSD 可以在斷電後保持資料數年，但接近 P/E cycle 上限的 cell，retention 時間可能縮短到幾個月甚至幾週。這就是為什麼企業級 SSD 通常會設定比消費級更保守的 endurance 規格。

這也是為什麼你的手機用了兩三年之後會感覺變慢。隨著 P/E cycle 累積，NAND flash cell 的 voltage margin 變窄，controller 需要更多次的 read retry 才能正確讀取資料，再加上長期使用後 garbage collection 的壓力增加，讀寫延遲都會上升。你感受到的「手機變慢」，有一部分就是 NAND flash 物理老化的結果。

以一顆 1 TB TLC SSD、P/E cycle 上限 3,000 為例：如果每次寫滿整顆 SSD 算一次 P/E cycle，理論上總共可以寫入
1 TB x 3,000 = 3,000 TB = 3 PB 的資料。但實際上因為 write amplification（後面會詳細討論），真正可寫入的資料量會比這個數字少很多。廠商標示的 TBW（Total Bytes Written）規格通常已經把 write amplification 考慮進去了。

Endurance & Retention

Endurance耐久度: 記憶體單元可以承受的寫入 / 擦除（Program/Erase, P/E cycles）次數。

問題來源：Repeated write/erase damage

解法：Wear Leveling, Over-Provisioning, Error Correction Code (ECC)

Retention資料保持時間: 在沒有電源的情況下，資料能維持正確的時間。

問題來源：Charge leakage

即使沒有操作，電子會慢慢穿過絕緣層（oxide）或受到溫度影響逃逸

解法：Refresh, ECC, Lower density（SLC > TLC > QLC）

Key Concepts
理解 SLC、MLC、TLC、QLC 的差異，以及它們在容量、速度與耐久性（endurance）之間的取捨

Answer

隨著每個單元（Cell）儲存的位元數從 1 (SLC) 增加到 4 (QLC)，容量成倍翻升，但代價是讀寫速度變慢，且物理磨損造成的壽命（Endurance）呈斷崖式下降。

Key Concept

Bits per Cell / Voltage Margin

Detail

SLC 只需區分 2 個電壓狀態，容錯率極高，讀寫極快且壽命長（可達 100k P/E cycles）。但 QLC 需要在相同的實體物理限制內，精細地劃分出 16 個電壓狀態。這使得寫入時需要非常小心的逐步微調（導致寫入極慢），且輕微的電荷流失就會跨越邊界導致讀取錯誤（導致壽命降至僅約 1k P/E cycles）。

理解 NAND flash 的儲存階層結構：page 是最小讀寫單位，多個 page 組成 block，block 再往上組成 plane 與 die

Answer

SSD 內部的儲存層級由小到大為：Cell → Page → Block → Plane → Die。其中，讀取與寫入的基本單位是 Page，而抹除的基本單位是 Block。

Key Concept

Asymmetric I/O Unit (非對稱 I/O 單位) / Storage Hierarchy

Detail

這是不對稱的硬體架構。主機平常是按 4KB 或 16KB（Page）在讀寫資料，但當 SSD 需要清空無效資料以釋放空間時，只能一次性抹除數 MB 的 Block。這正是衍生出 Garbage Collection (垃圾回收) 機制的根本原因。

理解 erase-before-write constraint，知道為什麼無法直接覆寫已寫入的 page，必須先將整個 block 抹除

Answer

物理上，寫入資料只能將電子「注入」儲存單元，無法單獨將電子「抽出」。若要清除電子，必須對整個 Block 施加高壓統一放電。

Key Concept

Fowler-Nordheim (FN) Tunneling

Detail

在 NAND Flash 中，沒有電子的狀態代表邏輯 1，注入電子代表邏輯 0。所謂的 Programming（寫入）只能把 1 變成 0。如果你想把 0 改回 1，唯一的物理手段就是執行 Erase，把整個 Block 裡的電子強制抽出。這就是不能原地覆寫 (In-place update) 的原因。

每個 block 的 P/E cycle 數量有限，並理解這如何決定 SSD 的壽命與 retention 特性

Answer

每一次的 Program 和 Erase 都會對儲存單元的絕緣層（Tunnel Oxide）造成不可逆的物理傷害。次數滿了會導致嚴重漏電，使資料無法長期保存。

Key Concept

Tunnel Oxide Degradation (隧道氧化層劣化) / Data Retention

Detail

電子進出 Floating Gate 會像子彈一樣打穿氧化層。隨著 P/E cycles 累積，絕緣層會產生越來越多的微小破洞（Charge Trapping）。這會讓原本關在裡面的電子慢慢逃逸，導致一段時間沒通電後，電壓產生偏移，這就是 Data Retention 下降的物理本質。

Test your understanding
假設你有兩顆容量相同的 SSD，一顆使用 SLC，一顆使用 QLC。在不考慮 controller 設計差異的情況下，它們各自適合什麼樣的 workload？請從 endurance、讀寫速度、成本三個角度分析。

Answer

SLC 適合高頻繁隨機寫入、極低延遲的企業級快取；QLC 適合大容量、以讀取為主的冷資料儲存。

Key Concept

Workload Matching / Cost-Performance Trade-off

Detail

  • SLC：Endurance 極高、讀寫最快，但單位成本 (Cost/GB) 昂貴，適合當資料庫的 Transaction Log 或 SSD 內部的 Cache 區塊。
  • QLC：Endurance 極低、寫入緩慢，但擁有極致的成本優勢，適合 WORM (Write Once, Read Many) 場景，如影音串流伺服器或資料備份歸檔。

一個 block 包含 256 個 page，每個 page 為 16 KB。如果你只需要更新其中一個 page 的資料，在最壞情況下需要搬移多少資料？這個 read-modify-write 的開銷與 block 大小的關係是什麼？

Answer

最壞情況下，為了更新 16 KB 的資料，必須讀取 4 MB 的舊資料、抹除新 Block，並寫回 4 MB 資料。Block 越大，寫入放大越嚴重。

Key Concept

Read-Modify-Write (RMW) / Write Amplification

Detail

這就是 Block-level mapping 的致命傷。一個 Block 總大小為 256 * 16 KB = 4096 KB (4 MB)。如果不能寫到新位置，就必須把整個 Block 搬出來修改，產生巨大的效能懲罰與無謂的 P/E cycle 損耗。

一顆 2 TB QLC SSD 的 P/E cycle 上限為 1,000 次。假設 write amplification factor 為 3，這顆 SSD 的預期寫入壽命（以 TB 為單位）大約是多少？請列出計算過程。

Answer

預期的主機可寫入量大約是 666 TB。

Key Concept

Total Bytes Written (TBW) Calculation

Detail

總物理可寫入壽命 = 2 TB * 1000 次 = 2000 TB。
因為 Write Amplification Factor 為 3 (主機每寫 1 份，SSD 底層要寫 3 份)，所以主機實際能寫入的資料量 = 總物理壽命 / WAF = 2000 / 3 = 666.67 TB。

為什麼 NAND flash 的 erase 操作只能以 block 為單位，而不能以 page 為單位？這個物理限制如何驅動了 out-of-place write 策略的採用？

Answer

因為抹除需要施加極高電壓，為了節省晶片面積，數萬個 Cell 會共用同一個基底（Substrate）電路，導致只能大面積抹除。這迫使 SSD 必須將新資料寫入其他空白 Page 以避開抹除延遲。

Key Concept

Shared Substrate / Out-of-place write 必然性

Detail

如果允許 In-place write，每次修改 4KB，底層都要先停下來耗費數毫秒抹除整個 Block。為了解決這個硬體缺陷，FTL 被發明出來，透過 Out-of-place write 將更新的資料一律寫入下一個空白的 Page，把漫長的 Erase 動作留給背景的 Garbage Collection 去處理。

隨著 P/E cycle 累積，cell 的 threshold voltage distribution 會如何變化？這對 SLC 和 QLC 各自的影響程度有什麼不同？請解釋原因。

Answer

電壓分布會因絕緣層受損而逐漸變寬、互相重疊。QLC 由於相鄰電壓狀態的間隔極小，受影響極其嚴重；SLC 則游刃有餘。

Key Concept

Voltage Distribution Shift / 容錯空間 (Margin)

Detail

想像一個房間要站人。SLC 只有「左半邊」和「右半邊」兩個狀態，就算老化導致界線有點模糊，還是能輕易分出左右。但 QLC 硬生生把房間切成了 16 等份（16 個 Voltage Levels），界線本來就極窄，一旦老化造成電壓飄移，狀態就會嚴重重疊，導致資料讀出時變成亂碼。

  1. 某資料中心需要部署一套「高寫入強度」的資料庫系統，預期三年內會持續進行大量隨機寫入。 工程師正在比較兩種 NAND flash 技術：

    方案 X : SLC (Single-Level Cell)
    方案 Y : QLC (Quad-Level Cell) 假設兩款 SSD 的總容量相同，且使用相同的 controller 設計。

    若考慮長期「可寫入總量 (Total Bytes Written, TBW)」，以下哪一項推論最合理？

    1. 兩者 TBW 應相同，因為 controller 設計相同。
    1. 方案 Y (QLC) TBW 較高，因為每次 erase 可以寫入更多位元。
    1. 方案 X (SLC) 通常具有較高 TBW，因為每個 cell 儲存的位元較少。
    1. 方案 Y (QLC) 通常具有較高 TBW，因為其容量較大，可以分散更多寫入。
    Answer

    方案 X (SLC) 通常具有較高 TBW，因為每個 cell 儲存的位元較少。

    解析:

    SLC 每個 cell 只儲存 1 bit，電壓區間較寬，對電壓漂移與干擾的容忍度較高，因此可承受較多的 P/E (Program/Erase) cycle。 QLC 每 cell 儲存 4 bits，需要更精細的電壓區分，導致 P/E cycle 上限顯著下降。 在高寫入 workload 下，endurance 成為決定 TBW 的主要因素，因此 SLC 通常具有較高 TBW。

  1. A data center recently replaced its SLC-based caching tier with QLC SSDs to save costs. After a year of heavy write workloads, the system administrators notice a severe increase in read tail latency, even when there are no ongoing background garbage collection (GC) operations.

    Based on the physical characteristics of NAND flash and error correction mechanisms, what is the fundamental reason for this read latency degradation?

    1. Because QLC does not support out-of-place updates, every time a page is updated, the controller must read the entire block, modify the 16KB page, and write the block back, severely blocking concurrent read requests.
    1. QLC flash requires managing 16 voltage levels within the same voltage window. As P/E cycles accumulate, the tunnel oxide degrades, causing the threshold voltage distributions to overlap. The controller must perform multiple read retries with shifted reference voltages (e.g., LDPC soft-decision decoding) to correctly sense the data, increasing read time.
    1. Because QLC cells can only endure around 1,000 P/E cycles, the SSD firmware artificially throttles the read speed to prevent read disturb errors from wearing out the remaining lifespan of the cells.
    1. QLC erase blocks are significantly larger than SLC erase blocks (e.g., 16MB vs. 2MB). Therefore, even without GC, the read operations must wait longer for the larger blocks to be physically energized before the pages can be sensed.
    Answer

    QLC flash requires managing 16 voltage levels within the same voltage window. As P/E cycles accumulate, the tunnel oxide degrades, causing the threshold voltage distributions to overlap. The controller must perform multiple read retries with shifted reference voltages (e.g., LDPC soft-decision decoding) to correctly sense the data, increasing read time.

    Why:

    This is correct. QLC stores 4 bits per cell, requiring 16 tight voltage levels. As P/E cycles increase, oxide damage causes these levels to widen and overlap. To recover data, the SSD controller uses advanced ECC like LDPC soft-decision decoding, which physically requires sensing the cell multiple times with different voltage thresholds, drastically increasing the read latency.

  1. 在購買 SSD 時，會發現 QLC NAND Flash 相較於 SLC NAND Flash 而言更加便宜，其中使 QLC NAND Flash 比較便宜的原因為?
    1. QLC 在製成上，浮閘物理上被切分成很多隔間，所以隔間內的製造難度降低了
    1. 同物理空間大小下，QLC 能擺進更多的 Cell，從而使 QLC NAND Flash 比較便宜
    1. 在相同的物理矽晶片面積下，QLC 能提供 4 倍的資料容量，降低單位容量的製造成本
    1. QLC 與 NVMe 契合度非常高，不用太花費心力去處理資料的轉換
    Answer

    在相同的物理矽晶片面積下，QLC 能提供 4 倍的資料容量，降低單位容量的製造成本

    解析:

    QLC 每個 Cell 可以儲存 4 個 bit，而 SLC 每個 Cell 可以儲存 1 個 bit，在同容量下，QLC 的 Cell 數量是 SLC 的 1/4，因此降低單位容量的製造成本。

  1. 某工程師嘗試更新一個 NAND flash page 的資料，在該 flash 的物理特性中，低電荷狀態 (Erased state) 被定義為邏輯「1」，而注入電荷後的狀態 (Programmed state) 被定義為邏輯「0」 今天他在實驗中想要「直接將部分的 bit 從 0 改回 1 」，而不進行 erase 的操作。 實驗結果發現更新失敗，其最可能的主要原因是什麼?
    1. programming 操作需要依序寫入 page，不能跳著寫
    1. programming 只能「注入」電荷，不能降低電荷
    1. NAND flash 不支援 partial write
    1. block 太大導致更新失敗
    Answer

    programming 只能「注入」電荷，不能降低電荷

    解析:

    programming 是把電荷注入 floating gate，只能加電子，不能減，因此需要 Erase-before-write

  1. A cloud provider needs to choose an SSD for a write-intensive logging workload that writes 20 TB of host data per day. Assume the following steady-state WAF for this workload. Two candidates:
    SSD ASSD B
    Capacity1 TB2 TB
    Cell typeTLCQLC
    P/E cycle limit3,0001,000
    Write amplification factor24

    Approximately how long will each SSD last before reaching its endurance limit?

    1. SSD A: ~150 days, SSD B: ~100 days
    1. SSD B lasts longer because it has 2x the capacity
    1. SSD A: ~75 days, SSD B: ~100 days
    1. SSD A: ~75 days, SSD B: ~25 days
    Answer

    SSD A: ~75 days, SSD B: ~25 days

    Why:

    TBW_A = 1 TB x 3,000 / 2 = 1,500 TB.
    At 20 TB/day, that is 1,500 / 20 = 75 days.

    TBW_B = 2 TB x 1,000 / 4 = 500 TB.
    At 20 TB/day, that is 500 / 20 = 25 days.

    Despite having half the capacity, SSD A lasts 3x longer because TLC's higher P/E endurance and lower WAF more than compensate.

  1. 你在實驗室挖到一顆前人留下來的 2 TB QLC SSD，其平均 P/E cycle count 約為 900 次，已接近該顆 QLC SSD 的額定 P/E cycle 壽命。你打算將它用於一個幾乎只有讀取、極少寫入的 workload。在這種使用情境下，你最可能面臨什麼挑戰？
    1. 因為該 workload 幾乎不包含寫入，P/E cycle count 在使用期間不會再有明顯上升，SSD 壽命不會進一步縮短。
    1. 由於這顆 QLC SSD 已接近其額定 P/E cycle 壽命，controller 可能需要更多次的 read retry 才能正確讀取資料，導致其 read throughput 低於該 SSD 在全新且經過 steady state 時的表現。
    1. 因為幾乎沒有寫入，不太需要 GC 搬移資料，所以幾乎不會產生 Write Amplification。
    1. 幾乎沒有寫入就不會觸發頻繁的 GC，所以在此情境下 SSD 的老化不會影響 read throughput。
    Answer

    由於這顆 QLC SSD 已接近其額定 P/E cycle 壽命，controller 可能需要更多次的 read retry 才能正確讀取資料，導致其 read throughput 低於該 SSD 在全新且經過 steady state 時的表現。

    解析:

    正確。隨著 P/E cycle 累積，NAND cell 的 threshold voltage distribution 會因 oxide 磨損而逐漸變寬。QLC 需要區分 16 個 voltage level，各 level 之間的 margin 本就極窄，老化後更容易重疊。controller 需要透過 read retry 來正確判讀資料，這些操作會增加讀取延遲，降低 read throughput。

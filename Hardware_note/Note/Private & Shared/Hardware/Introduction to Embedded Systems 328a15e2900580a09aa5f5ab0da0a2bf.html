sfr 與 sbit
sfr (Special Function Register - 特殊功能暫存器)

可用這個宣告暫存器變數。

一個 sfr 變數可以同時控制8個bits(等於一個Byte)。

在8051晶片上，有四排對外的接腳。

分別是 P0、P1、P2、P3，每一排剛好對應8個金屬腳位。

P0、P1的功能已經被定為外部記憶體的存取介面。P3上除了特殊功能外，P3.6、P3.7被規劃為外部記憶體的讀寫信號/WR、/RD，然後就用完了。

CLED.c

LED燈。直接定址。

利用 Char 變數以及位元反向 ( ~ ) 操作設定 P1 腳位的值，並呼喚 delay 函數讓輸出結果能停留一陣子(keep)，實做 LED 跑馬燈。

Code CLED.c
/* CLED.C for LED */

#include"reg51.h"
void delay(unsigned int s);
//void delay(unsigned char s);
void main()
{
	unsigned char LED;
	LED=0x01;
	P1=0xfe;
	while(1)
	{
		delay(8000);
		LED=LED<<1;
		if (LED == 0)
		{
		 	LED = 0x01;
		}
		//位元操作  : !僅操作一個位元; ~ 操作全部位元
		P1=~LED;
	}
}

void delay(unsigned int s)
{
	unsigned int m;
	for(m=0;m<s;m++);
}

  • delay(8000);

    單晶片執行速度極快（一秒鐘可以跑幾十萬次），LED 閃爍的速度會看起來像是一直全亮。呼叫延遲函式讓它停頓。

  • LED=LED<<1;

    讓LED變數左移一位元(最右側補0)。
    製造跑馬燈的錯覺。

  • if

		{
		 	LED = 0x01;
		}

    當全部LED燈變數全為0時(全亮)，將最右側bit設定為1(暗)。

  • P1=~LED;

    輸出最終值給P1。
    (~ 代表將LED的值反向輸出給P1，也就是LED燈會亮相反)

    註： ! 是邏輯反向，用在 True/False 判斷；~ 則是對全部 8 個位元逐一翻轉。

TMOD 計時/計數模式控制暫存器
TMOD = 0x21; //	SET TIMER1 MODE 2 and TIMER0 MODE 1. (00100001B)
//PT0 = 1; //IP.1 SET TIMER0 INTERRUPT HIGH PRIORITY
//TF0 = 0; //TCON.5 CLEAR TIMER0 OVERFLOW
//TH0 = (65536-20000)/256;
//TL0 = (65536-20000)%256; // -20000 = 45536 = #B1E0H
//TR0 = 1; //TCON.4 SET TIMER0 RUN

TMOD 是一個 8 位元的暫存器，高 4 位元控制 Timer 1，低 4 位元控制 Timer 0。是一個核心硬體暫存器，負責設定晶片計時器模式，寫入 00100001 。

  • GATE ：

    以 Timer 1為例，當 GATE = 0 且 TCON 的 TR1 = 1，啟動 Timer 1 此為內部啟動。
    當 GATE = 1 且 TCON 的 TR1 = 1 以及 INT1 為高電位時啟動 Timer 1 此為外部啟動。

    TCON

    TCON 暫存器高位四位元 TF1 ~ TR0 是計時 / 計數溢位旗標與啟動開關。低位四位元是外部中斷旗標與啟動開關。

    • TF1 ：TF1 中斷旗標。Timer 1 觸發中斷時自動設置 1，執行完中斷函式時自動清零。
    • TR1 ：TR1 啟動開關。TR1 設置 1 時啟動 Timer 1 ， TR1 設置 0 時關閉 Timer 1。
    • TF0 ：TF0 中斷旗標。Timer 0 觸發中斷時自動設置 1，執行完中斷函式時自動清零。
    • TR0 ：TR0 啟動開關。TR0 設置 0 時啟動 Timer 0 ， TR0設置 0 時關閉 Timer 0。
    • IE1 ：INT1 中斷旗標。發生 INT 1 中斷時自動設置 1，執行完中斷函式時自動清零。
    • IT1 ：INT1 中斷型態。INT1=1 負緣觸發，INT1=0 低準位觸發。
    • IE0 ：INT0 中斷旗標。發生 INT 0 中斷時自動設置 1，執行完中斷函式時自動清零。
    • IT0 ：INT1 中斷型態。INT0=1 負緣觸發，INT0=0 低準位觸發。
  • C/T ：

    內部計時 / 外部計數開關。

    當 C/T = 0 時使用系統時脈。
    當 C/T = 1 時計數器的時脈由 T1 ( Timer 1 )或 T0 ( Timer 0 ) 輸入，此時稱為外部計數。

  • 高 4 位元 0010：
    • 0 ( Gate = 0 ) 0 ( C/T = 0 ) 10 ( M1 = 1, M0 = 0 )
    • 00 使用內部系統時脈進行計時。
    • 10 設定 Timer 1 為 Mode 2
      • 作為不佔用 CPU 資源的序列通訊波特率產生器（Baud Rate Generator）。
      • 自動重載(Reload)功能:
        • TL1先被初始化成TH1的內容
        • TL1開始計數
        • TL1 overflow
        • Reload TL1並將TH1的值存入TL1中
  • 低 4 位元 0001：
    • 01 設定 Timer 0 為 Mode 1
      • 雖然在此程式中被註解未啟用，但原設計通常用於超音波回波（Echo）的時間量測

使用計時 / 計數器需要設定相關暫存器才能完成計數程序，TH1, TR1就是相關的暫存器。

設計 TH1 = 253 原因

透過石英震盪器除頻，調教 9600bps 使藍芽模組能順利運作。
由於PMOD的設定，除頻器並沒有額外受到參數影響(下節會詳細說明)，

石英晶體震盪器頻率為 11.0592MHz ，傳入8051晶片後會透過三個步驟除頻(使震盪頻率降低)。

  • 每12次震盪為一週期 → 11, 059, 200 / 12 = 921, 600 Hz
  • Timer 設定 (此程式碼設定 counter 每3次就會因為 overflow 重新計數) → 921, 600 / 3 = 307, 200 Hz
  • SMOD (在 PMOD 暫存器中的變數, 0 ⇒ 分流32; 1 ⇒ 分流16 ) → 307, 200 / 32 = 9600 Hz

剛好是藍芽模組需要的 9600 bps

bps 與 Hz 的核心差異在於：bps 是「數位資料」的傳輸量（多少資料），而 Hz 是「物理波動與頻率」的單位（多快頻率）

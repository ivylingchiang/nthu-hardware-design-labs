Verilog Introduction

Introduction

  1. 硬體描述語言（Hardware Description Language, HDL），用於數位電路的系統設計，是一種描述數位電路的語言。
    HDL 分為兩大類， Verilog 跟 VHDL
  1. 描述完電路想法後可利用 EDA Tools (Synopsys、Cadence 和 Siemens EDA等等) 完成電路設計(Simulation、 Synthesis、 Implementation、 Generate Bitstream)

Description methods (High → Low)

  1. Behavior Level
  1. Dataflow Level
  1. Gate Level
  1. Switch Level
  • 暫存器轉換層次 RTL (Register Transfer Level) : Dataflow Level + Behavior Level
  • 通常撰寫 Verilog 只會使用Behavior、Dataflow、Gate(較少) Level

      1. 表示法
        // 向量表示法
// [最高位元MSB : 最低位元LSB] 或 [最低位元LSB : 最高位元MSB]
/* 宣告 */
output [3:0] A;         // A為4bit，A[3]，A[2]，A[1]，A[0] <= 比較常用
reg [0:3] B;            // B為4bit，B[0]，B[1]，B[2]，B[3]
wire [63:0] D;          // D為64 bit
wire E;                 // E為1 bit
/* 使用 */
A[2:1] = B[0] & C[1:2]; // A[2] = 0&C[1]，A[1] = B[0] & C[2]
B[0:1] = 0;             // 清空B的最高(最左)2bit


// 陣列表示法
/* 宣告 */
// {位寬} {name} {陣列}
integer [7:0] A [3:0];      // A為4個8bit的integer
reg B [3:0] [15:0];         // C為4*16個1bit的reg
reg [7:0] C [3:0] [15:0];   // C為4*16個8bit的reg
/* 使用 */
A[3] = 0;                   // 清除A陣列中第3個元素(內含8bit)
A = 0;                      // 把陣列全部清空
B[1][0] = 1;                // 設定B陣列中[1][0]的元素為1
B[1] = 0;                   // 將[1][0]到[1][255]的元素都設為0
C[0][0][3:0] = 4b’0010;     // 設定位置[0][0]的低4bit為0010
C[2][8][5] = 1 ;            // 設定位置[2][8]的第5bit為1


// 記憶體表示法
// 由reg組成的陣列
/* 宣告 */
reg [15:0] A [1023:0]   // 記憶體A由1024個16bit字元組成
/* 使用 */
A[128];                 // 地址為128的字元(內含16bit)

    1. Description methods
      Gate Level

      <閘名稱> <閘name> ( 輸出埠, 輸入埠1, 輸入埠2… );

      閘名稱：使用的邏輯閘名稱( ex. and, or, nor... )

      閘name：可不寫

      輸出埠：只能有一個，寫在最前面

      輸入埠：輸入邏輯閘的資料口，需使用逗號分別

      // 全加器程式碼
module Full_Adder( A, B, Cin, Sum, Cout );

    input A, B, Cin;
    output Sum, Cout;
    wire W1, W2, W3;

    xor xor1( W1, A, B );
    and and1( W2, W1, Cin );
    and and2( W3, A, B );
    xor xor2( Sum, W1, Cin );
    or  or1( Cout, W2, W3 );

endmodule
      Dataflow Level

      Assign

      • 賦予某值至net ( 等號左式只能是net，右式可以是 net 或 reg ) → 可以想成接線
      • 只能敘述組合邏輯電路( combinational circuit)
      • 輸出不可以包含輸入 (Eg. a = a + b (x))
      assign 輸入 = 輸出

      運算子

      條件運算子

      Out = ( A>B ) ? A : B;

If( A>B )
    Out = A;
else
    Out = B;

      連結運算子

      A = { 1’b0, 1’b1 };         // A = 2’b01
A = { B[1:0], C[0], D[2] }; // A = B[1], B[0], C[0], D[2]
A = { 2{2’b01} };           // A = 4’b0101
A = { 3’b101, 2{1’b0} }     // A = 5’b10100
      // 全加器程式碼
module Full_Adder( A, B, Cin, Sum, Cout );

    input A, B, Cin;
    output Sum, Cout;

    wire W1, W2, W3;

    assign W1 = A^B;
    assign W2 = W1&Cin;
    assign W3 = A&B;
    assign Sum = W1^Cin;
    assign Cout = W2|W3;

endmodule
      Behavior Level

      always ( { events })

      • 驅動某值至reg( 等號的左邊一定要是 reg，右式可為net 或 reg )
      • 可用於 combinational circuit 、 sequential circuit
      • 當”事件”有變化時( 0→1、1→0 )，則會執行”敘述”，可使用正緣觸發posedge(0→1)或負緣觸發negedge(1→0)
      • always @(*) 或 always @ 代表always內的線路有任一變化即執行敘述
      // 全加器程式碼
module Full_Adder( A, B, Cin, Sum, Cout );

    input A, B, Cin;
    output Sum, Cout;

    wire W1, W2, W3;

    always @( A, B, Cin ) begin
        { Cout, Sum } = A + B + Cin;
    end

endmodule

Advance

  1. 不同的敘述方法會造成不同合成、不同效能的電路
  1. always中要使用 if - else 結構，最好保持在一個大 if-else 結構當中(可以有else if)，否則合成器有可能會合出不正確的硬體。
    if - else && case => 合成器會合成 MUX 
	// 條件互斥時使用
	// 否則以priority高者先match

block中多個if-else => 合成器合成 加法器
	// 多個條件同時成立
  1. 賦值時，檢查是否在任何情況中都有給定新值，否則合成器可能會合成出latch

    latch 可能會出現的電路問題

    問題說明
    level - sensitive在edge trigger處會出現race condition。
    glitchlatch enable時output會呈現與input相同的值，若input不穩定，則output也會呈現不穩定的狀態。
    PVT (Process / Voltage / Temperature) 變動行為不穩定enable path, data path, latch 關閉時間延遲不同，設計上容易有問題。
    simulation可能與真實情況不一致delay time導致的取值問題

    latch vs. Flip-flop

    latchFF
    觸發方式level - sensitiveedge - trigger
    Clock / EnableEnable Clock
    記憶特性Enable關閉時維持舊值自然記憶舊值，值到下一個trigger
    邏輯使用combinational電路中偶爾作為time borrowing或低功率設計大部分時序儲存單元
    Reset / Init需要額外撰寫容易實現(同步、非同步)
    使用場景少數高階設計：time borrowing pipeline、特殊 SRAM cell幾乎所有時序電路、暫存器、狀態機

  1. 常用的電路
    Debounce & One-Pulse

    Debounce

    機械按鈕或開關在按下或釋放瞬間會有「彈跳」（bounce），導致訊號在幾毫秒內快速跳變多次。Debounce 電路就是用來把這種不穩定訊號濾掉，輸出一個乾淨的邏輯訊號。

    輸入：彈跳的按鈕訊號

    輸出：穩定的按鈕狀態訊號

    Implement

    Method 1 (Counter)

    稍微複雜，需要計數器邏輯

    • 可精確控制濾波時間
    • 支援長按、長周期消抖
    module debounce(
    input clk,
    input btn_in,
    output reg btn_out
);

parameter N = 500000; // 50MHz * 0.01s = 500000

reg [19:0] cnt = 0;
reg btn_sync_0, btn_sync_1;

always @(posedge clk) begin
    btn_sync_0 <= btn_in;
    btn_sync_1 <= btn_sync_0;
end

always @(posedge clk) begin
    if(btn_sync_1 == btn_out) begin
        cnt <= 0;
    end else begin
        cnt <= cnt + 1;
        if(cnt == N) btn_out <= btn_sync_1;
    end
end

endmodule

    Implement Method (Shift Register)

    數位濾波 (digital filtering)

    • 簡單，少量邏輯
    • 高速時鐘下非常適合短暫抖動
    • 控制濾波時間不精確（取決於 shift register 長度 × 時鐘）
    module debounce(
    output pb_debounced, 
    input pb ,
    input clk
    );
    
    reg [6:0] shift_reg;
    always @(posedge clk) begin
        shift_reg[6:1] <= shift_reg[5:0];
        shift_reg[0] <= pb;
    end
    
    assign pb_debounced = shift_reg == 7'b111_1111 ? 1'b1 : 1'b0;
endmodule

    One-Pulse

    將一個長按訊號轉換成 固定寬度的一個脈衝，通常用於：

    • 讓一個按鈕觸發事件只執行一次
    • 避免長按造成多次觸發

    輸入：按鈕訊號（可能長按）

    輸出：一個時鐘週期寬度的單脈衝訊號

    Implement

    Method 1 (1 個 FF + AND/NOT)

    上升沿檢測是透過組合邏輯，沒有額外寄存器

    在高速 FPGA 或多 clk 設計時，可能需要注意同步問題

    module one_pulse(
    input clk,
    input btn,
    output pulse
);

reg btn_delay;

always @(posedge clk) begin
    btn_delay <= btn; 
end

assign pulse = btn & ~btn_delay; 

endmodule

    Method 2 (2 個 FF)

    op 在每個 clk 上升沿更新

    module onepulse(
    input signal, 
    input clk, 
    output reg op
    );
    
    reg delay;
    
    always @(posedge clk) begin
        if((signal == 1) & (delay == 0)) op <= 1;
        else op <= 0; 
        delay <= signal;
    end
endmodule
    Multiplexer & Demultiplexer

    Multiplexer

    多對一選擇電路，根據選擇訊號 (select lines)，從多個輸入中選擇一個輸出。

    Logic Formula (4 to 1 MUX)

    Implement

    Method 1

    module mux4to1(
    input [3:0] I,
    input [1:0] S,
    output reg Y
);
always @(*) begin
    case(S)
        2'b00: Y = I[0];
        2'b01: Y = I[1];
        2'b10: Y = I[2];
        2'b11: Y = I[3];
    endcase
end
endmodule

    Method 2

    assign Y = (S==2'b00)? I[0] :
           (S==2'b01)? I[1] :
           (S==2'b10)? I[2] :
                       I[3];

    Demultiplexer

    一對多分配電路，根據選擇訊號，把單一輸入訊號路由到多個輸出中的一個。
    Logic Formula (4 to 1 MUX)

    Implement

    DeMux 2 to 1

    module DeMux2_1( In, Sel, Out1, Out2 );

    input   In, Sel;
    output  Out1, Out2;

    wire    In, Sel;
    reg     Out1, Out2;

    always @( In, Sel ) begin
        case( Sel )
            1'b0: Out1 <= In;
            1'b1: Out2 <= In;
        endcase
    end

endmodule

    DeMux 4 to 1

    module demux4to1(
    input I,
    input [1:0] S,
    output reg [3:0] Y
);

always @(*) begin
    Y = 4'b0000;

        2'b00: Y[0] = I;
        2'b01: Y[1] = I;
        2'b10: Y[2] = I;
        2'b11: Y[3] = I;
    endcase
end
endmodule

    Comparator

    比較 A、B：> < == ；MSB → LSB cascade (找第一個不同 bit)

    module Comparator( In1, In2, Out );

    input   In1, In2;
    output  [2:0] Out;

    wire    In1, In2;
    reg     [2:0] Out;

    always @( In1, In2 ) begin
        Out[0] <= ( In1 > In2 );

    ALU

    根據 op code 選擇做哪個運算(reference link) 詳細設計根據spec來實做。

    Implement

    `define    ADD 2'b00
`define    SUB 2'b01
`define    AND 2'b10
`define    OR  2'b11

module ALU( Data_A, Data_B, OP_Code, Data_Out );

    parameter   Data_Size = 8;
    parameter   OP_Code_Size = 2;

    input   [Data_Size-1:0] Data_A, Data_B;
    input   [OP_Code_Size-1:0] OP_Code;
    output  [Data_Size-1:0] Data_Out;

    reg     [Data_Size-1:0] Data_Out;

    always @(*) begin
        case( OP_Code )
            `ADD:       Data_Out <= Data_A + Data_B;
            `SUB:       Data_Out <= Data_A - Data_B;
            `AND:       Data_Out <= Data_A & Data_B;
            `OR:        Data_Out <= Data_A | Data_B;
            default:    Data_Out <= 0;
        endcase
    end

endmodule

    module Counter( CLK, RST, Cnt_Num, Cnt_Data );

    parameter Cnt_Num_Size = 2;
    parameter Cnt_Data_Size = 16;

    input   CLK, RST;
    input   [Cnt_Num_Size-1:0] Cnt_Num;
    output  [Cnt_Data_Size-1:0] Cnt_Data;

    wire    CLK, RST;
    wire    [Cnt_Num_Size-1:0] Cnt_Num;

        else
            Cnt_Data <= Cnt_Data + Cnt_Num;
    end

endmodule
